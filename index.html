Separate dashboards for the field and the command post

Responders get a focused field view. Commanders get full situational awareness. Both share the same local database, so check-ins, incidents and live positions stay in sync.

Built for the field

Fully functional, in the browser

No Python, no build step, no framework. HTML, CSS and JavaScript with a local database.

Live GPS tracking

Use the browser Geolocation API for a real fix, or the built-in patrol simulation for a working demo anywhere.

Mapping + routing

OpenStreetMap, satellite and terrain layers with OSRM turn-by-turn routing and a graceful offline fallback.

Incidents + SOS

Report from the field with GPS lock. Critical reports and SOS alerts surface instantly in the admin portal.

Real local database

IndexedDB storage for users, teams, missions, incidents, messages and position history — with a localStorage fallback.
